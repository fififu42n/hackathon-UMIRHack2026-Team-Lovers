### 📋 Описание проекта
Данный репозиторий содержит замечательное и технологичное решение кейса от **банка «Центр-инвест»**. Мы разработали веб-сервис **«Онлайн-деканат»**, который помогает студентам и администрации вуза взаимодействовать быстрее, интуитивнее и без лишней бумажной бюрократии.

---

### ⚙️ Инструкция по запуску проекта

Чтобы развернуть проект локально у себя на компьютере, выполните следующие шаги:

#### 1. Клонирование репозитория и подготовка
Скачайте проект и откройте его в вашем любимом редакторе кода (например, **VS Code**):
```bash
git clone https://github.com
cd hackathon-UMIRHack2026-Team-Lovers/online-dean
```

#### 2. Установка зависимостей
Убедитесь, что у вас установлен Python, и установите все необходимые библиотеки:
```bash
pip install -r requirements.txt
```

#### 3. Запуск веб-приложения
Запустите главный файл сервера:
```bash
python app.py
```
 После этого откройте в браузере адрес, который появится в терминале (обычно `http://127.0.0.1:5000`), чтобы проверить работу сервиса.
